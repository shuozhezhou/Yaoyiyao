# 爻一爻 · 周易金钱卦

三枚铜钱、六掷成卦的周易起卦解卦小程序。

## 文件说明

| 文件 | 说明 |
|---|---|
| `爻一爻-单文件.html` | **自包含单文件**，双击用浏览器打开即可用；发给别人/传手机只需这一个文件 |
| `爻一爻.html` | 开发主文件（需与下面两个 js 放同一目录） |
| `yijing-data.js` | 六十四卦：卦辞、爻辞、白话、英文、大象传 |
| `yijing-detail.js` | 六十四卦：综合详解、分类断语（事业/感情/财运/健康/行动建议） |

## 功能

- 三枚铜钱法：正面(阳)=3、反面(阴)=2，六掷自下而上成卦
- 自动推出本卦、变卦、变爻，按变爻数套用传统读卦规则
- 卦象详解 + 按类别（综合/事业/感情/财运/健康）解读
- 提问输入、卦例历史（存本机）、中/英一键切换

## 打开方式

- **电脑**：右键 `爻一爻-单文件.html` → 用 Chrome / Edge 打开（别用编辑器预览，会白屏）
- **手机**：把 `爻一爻-单文件.html` 发过去，用系统浏览器打开（勿用微信内置浏览器）
- **发给他人测试**：建议部署成网站，分享链接最方便（见下）
